# Alpha Journey QA Factory v1

Run the reusable Alpha admission lane after an admitted change to the canonical
W1 Action learning loop:

```bash
./tools/run_alpha_journey_qa_v1.sh
```

The factory validates two truthful contracts. The fresh-install contract proves
placement and Welcome lead to Learn at `0/9`, with First Table Guide current and
Action locked. The Action-capability contract proves the Action loop only after
the versioned, production-equivalent prerequisite history completes the first
four W1 lessons. It never claims direct fresh-user Action reachability.

The Action replay starts before Action entry, uses visible Learn controls,
records its ordered telemetry trace, exercises correct-first and failed-recheck
policy paths, captures the Action raster lane at compact/tall/large phone
sizes, checks the frozen Modern Table ownership boundary, and packages local
only evidence. The legacy Modern Table screenshot generator is intentionally
excluded: it targets retired owners and is the known unrelated missing-import
failure.

Real Simulator Computer Use is required for learner-route truth. Deterministic
widget replay proves the Action capability under its declared precondition.
Direct-state harnesses remain limited to the separately labeled raster evidence
lane and cannot satisfy black-box trace validation.

Successful output is local only:

```text
output/review_bundles/canonical_journey_truth_progression_v1_<SHORT_SHA>/
output/review_bundles/canonical_journey_truth_progression_v1_<SHORT_SHA>.zip
output/review_bundles/canonical_journey_truth_progression_v1_<SHORT_SHA>.zip.sha256
```

The command emits separate `fresh_install_journey` and
`action_capability_journey` verdicts and fails closed for tracked edits, staged
output, a restored v1 direct-fresh-user contract, an unmet Action precondition,
a direct-state black-box trace, missing/misordered/duplicate required telemetry,
broken session-scoped or sequence continuity, unbound repair/recheck mapping,
incomplete compact/tall/large evidence, overflow, or missing recovered payoff.
Its manifest hashes all bundle files except itself; the archive hash is stored
beside the ZIP so creating it cannot invalidate the bundle.
