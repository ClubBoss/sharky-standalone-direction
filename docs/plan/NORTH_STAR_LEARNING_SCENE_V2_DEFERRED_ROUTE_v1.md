## 2. North Star relationship

Product North Star:

> The poker coach that turns mistakes into corrected table instincts.

Learning loop:

`SEE -> DECIDE -> UNDERSTAND -> REPAIR -> PROVE -> RETAIN`

The intended role of Learning Scene V2 is to strengthen **SEE -> DECIDE** while preserving the already-developed corrective loop. Visual immersion has no value if it weakens independent decision quality or leaks the answer.

## 3. Admission trigger

This route may be reconsidered only after current pre-Human gates and real novice evidence, or after an explicit owner re-admission supported by equally strong product evidence.

Examples of evidence that may justify admission:

- novices repeatedly fail to orient themselves at the table or confuse position;
- the learner does not notice the decisive table clue before acting;
- the current table and instructional lower surface feel cognitively disconnected;
- clue discovery or table-state comprehension is materially slow;
- current composition creates a material trust/premium gap that harms activation or learning engagement;
- accessibility evidence shows that the present composition does not scale cleanly while preserving the decision.

`DO NOTHING` remains a valid outcome if Human Novice Proof does not support a meaningful learning or product-value gain.

## 4. Candidate hypothesis set

Future comparison must keep the current Sharky experience as control and test at least:

### A. Current Sharky control

Current table/learning composition, with no structural redesign.

### B. Perspective / depth Sharky

A table scene that uses controlled perspective and spatial depth so that near/far seats, hero location, acting position, pot, price, and action context become easier to parse as a poker scene rather than a collection of labels.

### C. Perspective / depth + contextual coaching

The same spatial table concept plus concise coaching integrated above or inside the table scene, so guidance remains visually attached to the decision context instead of becoming a detached text panel.

No candidate is pre-selected as the winner by this document.

## 5. Candidate mechanics to study

- restrained perspective table geometry;
- near/far seat depth and stronger hero/position orientation;
- spatial HUD attached to the object it describes: pot, to-call, bet/raise, stack, actor;
- contextual coach presence above/in the table scene;
- table, instruction, feedback, and controls composed as one learning scene;
- premium depth hierarchy using lighting, material separation, environment, and companion presence only where it improves comprehension/trust;
- one clear focal clue per decision state;
- a bottom interaction region that remains part of the same scene rather than a second product below the table;
- clean behavior at both 1.0x and canonical 1.4x text scale.

## 6. Anti-answer-leak contract

A future contextual coach must guide **attention**, not provide the decision.

Do not highlight or name the exact decisive semantic feature in a way that makes the assessed choice trivial before commitment.

Preferred principle:

`show where/how to look -> learner interprets -> learner decides`

Rejected principle:

`highlight the answer-bearing words -> learner matches cue -> product counts it as independent skill`

Any candidate that improves visual clarity while increasing answer leakage loses the comparison.

## 7. Mandatory evaluation dimensions

A future concept/prototype comparison must measure or directly adjudicate:

1. time to understand the table state;
2. position recognition / orientation;
3. decisive-clue detection;
4. answer-leakage risk;
5. decision latency;
6. CTA and action-control clarity;
7. learner-visible continuity from table -> feedback -> repair -> recheck -> payoff;
8. 1.0x / 1.4x accessibility and reachability;
9. subjective premium / trust / desire-to-continue;
10. regression risk to deterministic route, learning truth, and telemetry.

Beauty alone is not an acceptance criterion.

## 8. First future artifact

It should show the same learning state under A/B/C, then select or reject the new direction against the evaluation dimensions above.
