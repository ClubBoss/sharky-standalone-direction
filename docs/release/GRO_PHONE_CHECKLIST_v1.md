# GRO · owner iPhone pass (~10 minutes of checks)

Use a development-signed iPhone build with normal Act0 routing, a clean
eligible world milestone available, and no previous review cooldown. See
[GRO entries](GRO_ENTRIES_v1.md) for the routes; do not complete a whole world
during this timed checklist if it can be prepared beforehand. Keep the same
installation/data for the no-repeat check.

- [ ] **Real share sheet (3 min):** Result → Share result → Share. Native iOS
  sheet opens; an installed target (e.g. Messages) and Copy are available.
  Open a target without sending, verify the exact preview text/link arrives;
  cancel and return to Sharky. No automatic post.
- [ ] **Store review (3 min):** earn a clean world result and stay on it for
  at least 2 seconds with no other sheet open. Observe one real Apple review
  sheet, dismiss without rating; learning remains usable. If StoreKit
  suppresses the sheet, record **not observed**, not a pass or a repeat
  request. Use a build/distribution where StoreKit permits review presentation.
- [ ] **No repeat (4 min):** return to learning, foreground/relaunch the same
  installation and reach another eligible world result when prepared. Wait
  at least 2 seconds; no second review sheet. Do not delete/reset learner data
  or reinstall between requests. If another earned result is not available,
  record the repeat check pending rather than treating a relaunch alone as proof.

Record device/build and pass / fail / not observed for these three checks.
