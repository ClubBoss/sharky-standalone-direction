# Quiet-test feedback

Ask after the session, without explaining the intended answers first.

1. What did you think you were supposed to do when you first opened Sharky?
2. Which part, if any, was unclear or made you pause?
3. How did you understand the explanations after your choices, including any incorrect ones?
4. What, if anything, can you do now that you could not do before?
5. Would you open Sharky again tomorrow? What makes you say that?
