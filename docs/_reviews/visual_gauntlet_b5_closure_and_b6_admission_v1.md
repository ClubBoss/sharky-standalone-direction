## 6. B6 product objective

B1 gave spatial depth.
B2 gave physical materials/environment.
B3 gave player embodiment.
B4 attached information to poker objects.
B5 gave deterministic visual salience.

B6 must now make STATE CHANGE itself visually legible.

Target transformation:

`state-aware static coaching scene`

->

`premium coaching scene where restrained motion communicates meaningful learning-state transitions`

Motion must explain change.

Motion must not exist merely to make the product feel animated.

Core principle:

`SEMANTIC MOTION, NOT DECORATIVE MOTION`.

## 7. B6 primary ownership

B6 owns motion only where an existing deterministic event/state transition
already exists.

### 7.1 DECISION -> FEEDBACK

The learner should clearly perceive:

`choice committed -> state changed -> verdict / causal explanation became current`

Do not visually reveal correctness before evaluation.

### 7.2 FEEDBACK -> REPAIR

The scene should help the learner reacquire the exact relevant context/clue
without changing repair semantics.

### 7.3 REPAIR -> RECHECK

The visual system should clearly release repair assistance and restore normal
recognition context.

No standing clue may survive into recheck.

### 7.4 RECHECK -> RESULT / CONTINUATION

The learner should understand that the recognition attempt has completed and
the scene is moving on.

### 7.5 B5 SALIENCE HANDOFF

Motion may interpolate existing B5 attention values where useful.

It must not create a second salience/state system.

## 8. Allowed B6 motion

Examples of admissible mechanisms when evidence supports them:

- short opacity transitions;

- material/luminance interpolation;

Motion must never own truth.

The semantic state must remain correct and understandable at the motion
endpoints and with motion reduced/disabled.

Required:

- deterministic state-driven triggers;
- no timing-based poker correctness;
- no animation required for telemetry;
- no animation required for navigation;
- no input blocked longer than necessary;
- no moving eligible target that harms answer fairness;
- no answer leakage;
- no persistent decorative loops;
- reduced-motion/accessibility-safe behaviour;
- screenshot endpoint determinism preserved.

Resting geometry must remain compatible with accepted B1-B5 evidence.

## 13. Acceptance bar

B6 is INSUFFICIENT if:

- motion is mostly decorative;
- motion makes the UI feel busier;
- correct answer becomes visually predictable before evaluation;
- eligible answers become unequally weighted;
- clue remains animated/highlighted into recheck;
- animation blocks interaction;
- animation changes layout endpoints;
- reduced-motion users lose meaning;
- screenshot determinism becomes unreliable;
- transitions feel slow;
- motion competes with teaching copy;
- characters/room start performing unrelated idle animation;
- B6 becomes a disguised B7 polish wave.

A strong B6 should make these transitions immediately understandable:

DECISION:

`I committed a choice.`

FEEDBACK:

`The state changed; here is why.`

REPAIR:

`Here is the same relevant context to use.`

RECHECK:

`The assistance is gone; recognise it yourself.`
