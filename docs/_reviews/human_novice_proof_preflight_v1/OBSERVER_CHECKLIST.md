# Observer Checklist

Record observed behavior, exact learner words, timestamps, and intervention level; do not translate hesitation into a defect during the session.

| Checkpoint | Record |
| --- | --- |
| Entry | First tap, time to meaningful action, hesitation, wrong navigation |
| Table orientation | Private cards, board, pot, `You`, `BTN`, dealer-marker identification without explanation |
| Decision | Stated question meaning, table evidence used, decision time, `Not sure yet` discovery, unnecessary scroll |
| Feedback | Learner's explanation of result/clue and next action |
| Review | Meaning of Review, discovery/actionability of `Practice this spot`, lower-space perception, scrolling/abandonment |
| Repair | Why retry appeared, reuse of clue, visibility/meaning of `Save this read`, recognition of completed state |
| Payoff | “What did you learn?” “What would you look at first on the next poker table?” “What mistake did the app help you fix?” “What would you do next in the app?” |

Do not lead, correct, or discuss aesthetics while the task is underway.
