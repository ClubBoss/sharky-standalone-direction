# Issue Classification

- **P0:** crash, data loss, impossible route, or no usable action.
- **P1:** primary action unreachable, learner cannot continue, required content clipped, wrong state/identity, or broken Review/repair loop.
- **P2:** material comprehension defect, misleading hierarchy, or repeated moderator intervention.
- **HUMAN_QA_HYPOTHESIS:** hesitation or aesthetic concern without repeated behavioral evidence.
- **OBSERVATION_ONLY:** preference or isolated comment without behavioral impact.

One participant’s taste is not a product defect. Capture exact reproduction, first failing owner, and stop for separately authorized repair on any P0/P1.
