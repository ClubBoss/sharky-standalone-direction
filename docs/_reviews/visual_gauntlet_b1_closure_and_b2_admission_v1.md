## 5. B2 product objective

B1 made the scene spatially correct.

B2 must make that spatial scene materially more premium.

Target transformation:

`B1 spatially coherent character-ready poker scene`

->

`B2 premium poker environment with a table that feels like a designed physical object inside an intentional room`

This is the first true art/material/environment wave.

The result should make a large immediate visual jump toward the quality class
represented by the owner-supplied PokerSkill benchmark while preserving
Sharky's own identity.

PokerSkill is a benchmark, not a clone target.

## 6. B2 primary ownership

### 6.1 Premium table material

B2 owns:

- felt treatment;
- rail material;
- rail volume;
- table edge;
- table silhouette refinement where necessary;
- physical/material separation;
- lighting response;
- table grounding;
- premium perception.

### 6.2 Environment / room art

Replace B1's structural room placeholder with a coherent premium environment.

B2 owns:

- wall/background;
- floor/lower environment;
- horizon;
- lighting logic;
- ambient depth;
- room framing;
- atmospheric separation;
- foreground/background relationship.

The room must support the poker scene. It must not become casino spectacle.

### 6.3 Lighting system

Create one coherent lighting model.

At minimum:

- table key light;
- environmental falloff;
- player-volume readability;
- hero/near-plane readability;
- board readability;
- rail material readability.

Avoid random glow per widget.

### 6.4 Vertical scene composition

B1 identified insufficient vertical room for a fully readable far-player plane.
B2 owns the bounded table/environment vertical trade required to improve:

- far-player visibility;
- environment framing;
- table placement;
- hero/far-player relationship.

Wave A learning hierarchy must remain intact.

Do not shrink critical interaction targets or teaching copy merely to gain room.

### 6.5 Protected B1 depth foundation

Do not replace the B1 perspective architecture casually.

Preserve and build on:

`environment -> farPlayer -> table -> nearPlayer -> overlay`

Preserve:

- seat slots;
- character-safe volumes;
- `characterAnchor`;
- `plateAnchor`;
- `betAnchor`;
- `cardAnchor`;
- hero zone.

B2 art must attach to this system.

## 9. B2 iteration strategy

Use two strong internal iterations by default.

### Iteration 1 - table physicality + material system

Goal: the table stops reading as a styled Flutter shape and begins reading as a
premium physical poker table.

### Iteration 2 - room + light + vertical composition

Goal: the scene becomes one coherent premium environment and the player/table
planes are substantially better framed.

Allow iteration 3 only if one large B2 class-level gap clearly survives.

Do not spend execution budget on micro-polish.

## 10. B2 acceptance bar

A viewer should immediately see:

- a materially more premium table;
- believable rail/felt separation;
- coherent environment;
- intentional lighting;
- stronger far/near depth;
- better use of vertical space;
- table physically belongs to the room;
- B1 player slots feel naturally ready for B3 character art.

If the result is merely `same B1 scene with more gradients, glow, and shadows`,
B2 is insufficient.
