## Gate A verdict

**B — reuse the existing preview-shell owner. Gate B admitted.**

The preview shell already owns the only canonical route, task selection,
repair/recheck lifecycle, completion, progression, persistence, and telemetry
context. A thin source contract explicitly links `actions_theory` and
`actions_check_drill`; it does not infer membership from names, copy, routes,
or widget state.

## Context, geometry, and repair truth

The sequence key is `w1_action_words_check_v1`. Its table-context key is
`w1_action_words_no_bet_read_v1` with relation `related_read`, explicitly not
a same-hand claim. The compact geometry policy sets both admitted Action task
surfaces to a 520px table-height policy; practice uses a deterministic 264px
lower panel and places feedback CTA after a 16px content gap rather than using
the former content-to-footer spacer.

A wrong Action decision enters the explicit same-task repair; a correct repair
enters the explicit same-task recheck. A failed repair repeats repair; a failed
recheck returns to repair. This is truthfully a repeated no-bet read using the
existing runner, not a claimed fresh hand or fabricated poker state.

## Scope, risk, and rollback

Affected owners: the new contract, `Act0LessonRunnerShellV1`,
`Act0ShellPreviewScreenV1`, and focused tests. No W1-W12 migration, runner
replacement, progression-engine replacement, dependency, or alternate route
is introduced. Rollback is one bounded removal of sequence resolution and its
preview-shell transition; unannotated tasks retain their legacy geometry.

Residual evidence work is limited to rerunning the local sequence capture
packet on the changed geometry. Learner-only/dealer-order source admission is
separate and remains out of scope.
