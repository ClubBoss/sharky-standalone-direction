# Feedback / Repair / Session Closure C2 Design Spec v1

Terminal verdict: `feedback_repair_session_closure_c2_scope_confirmed_wrong_feedback_and_repair_focus_dead_space_plus_session_summary_rhythm_is_highest_ev_bounded_wave_terminal_chip_and_session_repair_deferred_on_evidence_gap`

## Scope

Primary states: wrong feedback and repair focus. Both must read as a repair
learning moment: missed clue or repair target, focused action, table context,
and one clear next action. Table remains context, never the dominant surface;
no table redesign is admitted.

Session summary is secondary and may be touched only after fresh compact
evidence confirms the reported competing-panel and bottom-nav clipping issue.
Correct feedback and repair result are regression controls, not primary C2
scope. W12 payoff and the no-W13 chip remain separate. Session repair remains
excluded until a fresh capture proves a distinct state.

## Constraints

No new repair semantics, proof, mastery, achievements, streaks, routes,
telemetry, Sharky assets, W13 behavior, motion, tablet work, or dependencies.
Keep copy claim-safe and preserve existing CTA and continuation behavior.

## Gate

Before source work, regenerate literal compact evidence for wrong/correct
feedback, repair focus/result, session repair, and session summary through the
full real-text repair lifecycle. Implement only if the shared wrong-feedback /
repair-focus dead-space and hierarchy defects reproduce. Stop for a broad
runner rewrite, new data model, or unconfirmed session-summary defect.

No 10/10, public-readiness, Human-QA-readiness, or tablet-quality claim is
made.
